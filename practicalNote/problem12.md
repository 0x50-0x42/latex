# Need bigger fonts (bigger than `\Huge`)

* Use the [`memoir`](https://mirror.niser.ac.in/ctan/macros/latex/contrib/memoir/memman.pdf) document class, it has has 12 font sizes.
	* To use those fonts sizes, use the `extrafontsizes` option as: `\documentclass[extrafontsizes,25pt]{memoir}`.
* You can also use [Extsizes package](https://mirror.niser.ac.in/ctan/macros/latex/contrib/extsizes/extsizes.pdf).

* Source: [https://latex-tutorial.com/changing-font-size/](https://latex-tutorial.com/changing-font-size/).
